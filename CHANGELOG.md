# Changelog

## v0.1.0 - 2026-06-08

Initial release of TexMap.

- Interactive CD8 T-cell exhaustion atlas explorer.
- Continuous Tex axes for exhaustion, stemness, terminality, cytotoxicity, proliferation, and chromatin fixation.
- Demo atlas generation and projection workflow.
- Regulatory-network, clinical benchmark, multiomic, cross-species, CELLxGENE, TexAPI, and TexAgent modules.
- Documentation, tutorials, quick start guide, and example integration figures.
